QSMxT: Quantitative Susceptibility Mapping tool (Rust)

Usage: qsmxt <COMMAND>

Commands:
  run            Run the full QSM pipeline on a BIDS dataset
  init           Generate a pipeline configuration file
  validate       Validate BIDS dataset structure for QSM processing
  dicom-convert  Convert a DICOM directory to BIDS using automatic series classification
  slurm          Generate SLURM job scripts for HPC execution: one job per run, then an aggregation job
  aggregate      Run the dataset-level steps over runs already processed with `qsmxt run --no-dataset-steps` (multi-orientation, summary tables, provenance, clean-up)
  mask           Masking operations
  combine        Multi-coil phase combination (uncombined receive-coil channels -> combined echoes)
  unwrap         Phase unwrapping
  fieldmap       B0 field mapping from multi-echo phase (NIfTI in, ppm out)
  bgremove       Background field removal
  invert         Dipole inversion
  separate       Susceptibility source separation
  qsmart         QSMART vessel-aware reconstruction: total field -> susceptibility
  swi            Susceptibility-weighted imaging
  segment        Whole-brain segmentation of a magnitude image with SynthSeg
  r2star         R2* mapping from multi-echo magnitude data
  t2star         T2* mapping from multi-echo magnitude data
  r2             R2 mapping from multi-echo spin-echo (MESE) magnitude data (EPG)
  r2prime        R2' mapping: measured as R2* - R2, or estimated from R2* by R2PRIMEnet
  homogeneity    Inhomogeneity correction on magnitude data (makehomogeneous or N4)
  resample       Resample oblique volume to axial orientation
  quality-map    Compute ROMEO phase quality map
  example        Download an example BIDS dataset to try the pipeline on
  tui            Launch interactive TUI for pipeline configuration
  update         Check for updates and optionally install the latest version
  news           Show the announcements from the QSMxT team, newest first
  help           Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help

  -V, --version
          Print version
