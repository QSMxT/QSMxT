Rapid Two-Step (RTS)

Usage: qsmxt invert rts [OPTIONS] --mask <MASK> --output <OUTPUT> <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling) (if omitted: the whole volume at once)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --rts-delta <RTS_DELTA>
          RTS: Threshold for ill-conditioned k-space region (default: 0.15)

      --rts-mu <RTS_MU>
          RTS: Regularization parameter for well-conditioned region (default: 100000)

      --rts-rho <RTS_RHO>
          RTS rho (ADMM penalty) (default: 10)

      --rts-tol <RTS_TOL>
          RTS: Convergence tolerance (relative change) (default: 0.01)

      --rts-max-iter <RTS_MAX_ITER>
          RTS: Maximum ADMM iterations (default: 20)

      --rts-lsmr-iter <RTS_LSMR_ITER>
          RTS: LSMR iterations for step 1 (well-conditioned solve) (default: 4)

      --rts-tau <RTS_TAU>
          RTS: rho is raised when the primal residual falls by less than this factor (tau) (default: 0.7)

      --rts-gamma <RTS_GAMMA>
          RTS: the factor rho is raised by (gamma) (default: 5)

      --rts-pad <X> <Y> <Z>
          RTS: Zero-padding before the FFTs (x y z): at least this many, rounded up to an FFT-efficient size; -1 leaves an axis unpadded, in voxels (default: 0 0 0)

  -h, --help
          Print help
