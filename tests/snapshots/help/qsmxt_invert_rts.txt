Rapid Two-Step (RTS)

Usage: qsmxt invert rts [OPTIONS] --mask <MASK> --output <OUTPUT> <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --delta <DELTA>
          Delta parameter

      --mu <MU>
          Mu parameter

      --tol <TOL>
          Tolerance

      --rho <RHO>
          Rho (ADMM penalty)

      --max-iter <MAX_ITER>
          Max iterations

      --lsmr-iter <LSMR_ITER>
          LSMR iterations

      --tau <TAU>
          Rho is raised when the primal residual falls by less than this factor (tau)

      --gamma <GAMMA>
          The factor rho is raised by (gamma)

      --pad <X> <Y> <Z>
          Zero-padding before the FFTs in voxels, X Y Z: at least this many, rounded up to an FFT-efficient size; -1 leaves an axis unpadded (default: 0 0 0)

  -h, --help
          Print help
