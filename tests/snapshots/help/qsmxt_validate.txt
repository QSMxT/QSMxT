Validate BIDS dataset structure for QSM processing

Usage: qsmxt validate [OPTIONS] <BIDS_DIR>

Arguments:
  <BIDS_DIR>
          Input BIDS directory

Options:
      --include <INCLUDE>...
          Include only runs matching these glob patterns (e.g. "sub-1*" "*ses-pre*") (if omitted: every run)

      --exclude <EXCLUDE>...
          Exclude runs matching these glob patterns (e.g. "*mygrea*") (if omitted: none)

  -h, --help
          Print help
