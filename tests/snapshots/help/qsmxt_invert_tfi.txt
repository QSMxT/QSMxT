Total Field Inversion (preconditioned). Input is the TOTAL field (not a local field)

Usage: qsmxt invert tfi [OPTIONS] --mask <MASK> --output <OUTPUT> --field-strength <FIELD_STRENGTH> --echo-times <ECHO_TIMES>... --magnitude <MAGNITUDE>... <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --field-strength <FIELD_STRENGTH>
          B0 field strength in Tesla

      --echo-times <ECHO_TIMES>...
          Echo times in seconds, every echo's, in order

      --magnitude <MAGNITUDE>...
          Magnitude of every echo: one 4D NIfTI, or one 3D NIfTI per echo in echo order

      --kernel <KERNEL>
          Dipole kernel on a grid with an odd number of voxels along an axis: default samples the dipole on the Fourier grid; original samples it half a frequency step off, as the original implementation does, for comparison with it. Identical on even grids (default: default)

          [possible values: default, original]

      --precision <PRECISION>
          Arithmetic: double, or single as the original implementation runs, for comparison with it (default: double)

          [possible values: double, single]

      --tfi-lambda <TFI_LAMBDA>
          TFI lambda: the data-fidelity weight (larger fits the field more closely) (default: 1000)

      --tfi-precond <TFI_PRECOND>
          TFI: Preconditioner value (susceptibility scaling outside the mask) (default: 30)

      --tfi-percentage <TFI_PERCENTAGE>
          TFI edge percentage (0.0-1.0) (default: 0.9)

      --tfi-max-iter <TFI_MAX_ITER>
          TFI: Maximum outer iterations (default: 10)

      --tfi-cg-max-iter <TFI_CG_MAX_ITER>
          TFI: Maximum conjugate gradient iterations (default: 100)

      --tfi-cg-tol <TFI_CG_TOL>
          TFI: CG convergence tolerance (default: 0.01)

      --tfi-tol <TFI_TOL>
          TFI: Outer convergence tolerance (default: 0.1)

      --tfi-merit <TFI_MERIT>
          TFI: enable MERIT weighting (default: true)

          [possible values: true, false]

      --tfi-linear <TFI_LINEAR>
          TFI: fit the field linearly, as the TFI paper does (default: true); false uses MEDI's exponential data term

          [possible values: true, false]

      --tfi-data-weighting <TFI_DATA_WEIGHTING>
          TFI: data weighting mode (0=uniform, 1=SNR) (default: 1)

      --tfi-te <TE>
          TFI: the echo time the field is converted to phase at: first, last, spacing (TE2 - TE1), sum (of the echo times), or a time in ms (default: spacing)

  -h, --help
          Print help
