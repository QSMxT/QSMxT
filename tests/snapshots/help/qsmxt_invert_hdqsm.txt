Hybrid Data-Fidelity QSM

Usage: qsmxt invert hdqsm [OPTIONS] --mask <MASK> --output <OUTPUT> --echo-times <ECHO_TIMES>... --magnitude <MAGNITUDE>... <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --echo-times <ECHO_TIMES>...
          Echo times in seconds, every echo's, in order

      --magnitude <MAGNITUDE>...
          Magnitude of every echo (the data weight is their echo-time-weighted combination): one 4D NIfTI, or one 3D NIfTI per echo in echo order

      --hdqsm-alpha-l2 <HDQSM_ALPHA_L2>
          HD-QSM L2-stage TV weight (alpha_l2) (default: 3e-5)

      --hdqsm-mu1-l2 <MU1_L2>
          HD-QSM L2-stage gradient-consistency ADMM weight (mu1_l2), or auto for 100 × alpha_l2 (default: auto)

      --hdqsm-mu2 <HDQSM_MU2>
          HD-QSM fidelity consistency weight (mu2) (default: 1)

      --hdqsm-max-iter-l1 <HDQSM_MAX_ITER_L1>
          HD-QSM stage-1 (L1) iterations (max_iter_l1) (default: 20)

      --hdqsm-max-iter-l2 <HDQSM_MAX_ITER_L2>
          HD-QSM stage-2 (L2) iterations (max_iter_l2) (default: 80)

      --hdqsm-tol-update <HDQSM_TOL_UPDATE>
          HD-QSM stage-2 percent-update convergence tolerance (default: 0.01)

  -h, --help
          Print help
