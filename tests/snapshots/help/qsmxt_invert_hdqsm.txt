Hybrid Data-Fidelity QSM

Usage: qsmxt invert hdqsm [OPTIONS] --mask <MASK> --output <OUTPUT> --echo-times <ECHO_TIMES>... --magnitude <MAGNITUDE>... <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --echo-times <ECHO_TIMES>...
          Echo times in seconds, every echo's, in order

      --magnitude <MAGNITUDE>...
          Magnitude of every echo (the data weight is their echo-time-weighted combination): one 4D NIfTI, or one 3D NIfTI per echo in echo order

      --alpha-l2 <ALPHA_L2>
          L2-stage TV weight (alpha_l2)

      --mu1-l2 <MU1_L2>
          L2-stage gradient-consistency ADMM weight (mu1_l2), or auto for 100 × alpha_l2 (default: auto)

      --mu2 <MU2>
          Fidelity consistency weight (mu2)

      --max-iter-l1 <MAX_ITER_L1>
          Stage-1 (L1) iterations (max_iter_l1)

      --max-iter-l2 <MAX_ITER_L2>
          Stage-2 (L2) iterations (max_iter_l2)

      --tol-update <TOL_UPDATE>
          Stage-2 percent-update convergence tolerance

  -h, --help
          Print help
