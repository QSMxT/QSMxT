Improved HARPERELLA (iHARPERELLA)

Usage: qsmxt bgremove iharperella [OPTIONS] --mask <MASK> --output <OUTPUT> <INPUT>

Arguments:
  <INPUT>
          Input NIfTI: a wrapped echo in rad (with --te and --field-strength) or a total field in ppm

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output local field NIfTI file

      --output-mask <OUTPUT_MASK>
          Output eroded mask (for algorithms that erode)

      --te <TE>
          Echo time (s) of a wrapped-phase input. With --field-strength, the input is one wrapped echo in rad, unwrapped by HARPERELLA's Laplacian; if both are omitted, it is an unwrapped total field in ppm, which iHARPERELLA takes as it is. The local field is written in ppm either way

      --field-strength <FIELD_STRENGTH>
          B0 field strength (T) of a wrapped-phase input — see --te for when both are omitted

      --iharperella-max-iter <IHARPERELLA_MAX_ITER>
          iHARPERELLA: Maximum iterations (default: 40)

      --iharperella-tol <IHARPERELLA_TOL>
          iHARPERELLA: Convergence tolerance (default: 0.001)

      --iharperella-pad <X> <Y> <Z>
          iHARPERELLA zero-padding in voxels per side, X Y Z (default: 0 0 0)

      --iharperella-rim <RIM>
          iHARPERELLA boundary rim: whole (zero every Laplacian value in the rim) or sti (zero the 20 % largest, as STI Suite does; default)

  -h, --help
          Print help
