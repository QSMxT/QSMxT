Nonlinear Total Variation

Usage: qsmxt invert nltv [OPTIONS] --mask <MASK> --output <OUTPUT> --field-strength <FIELD_STRENGTH> --echo-times <ECHO_TIMES>... --magnitude <MAGNITUDE>... <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling) (if omitted: the whole volume at once)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --field-strength <FIELD_STRENGTH>
          B0 field strength in Tesla

      --echo-times <ECHO_TIMES>...
          Echo times in seconds, every echo's, in order

      --magnitude <MAGNITUDE>...
          Magnitude NIfTI, the data weight (required): one 3D volume, a 4D one, or one per echo; several echoes are RSS-combined

      --nltv-lambda <NLTV_LAMBDA>
          NLTV: Regularisation parameter (default: 0.001)

      --nltv-rho <RHO>
          NLTV rho (ADMM penalty), or auto for 100 × lambda (default: auto)

      --nltv-mu <NLTV_MU>
          NLTV mu (penalty parameter) (default: 1)

      --nltv-tol <NLTV_TOL>
          NLTV: Convergence tolerance (default: 0.001)

      --nltv-max-iter <NLTV_MAX_ITER>
          NLTV: Maximum ADMM iterations (default: 250)

      --nltv-tol-newton <NLTV_TOL_NEWTON>
          NLTV: Convergence tolerance of the Newton iterations of the data-term subproblem (default: 1e-6)

      --nltv-newton-iter <NLTV_NEWTON_ITER>
          NLTV: Maximum Newton iterations of the data-term subproblem (default: 10)

      --nltv-te <TE>
          NLTV: the echo time the field is converted to phase at: first, last, spacing (TE2 - TE1), sum (of the echo times), or a time in ms (default: first)

      --nltv-pad <X> <Y> <Z>
          NLTV: Zero-padding before the FFTs (x y z): at least this many, rounded up to an FFT-efficient size; -1 leaves an axis unpadded, in voxels (default: 0 0 0)

  -h, --help
          Print help
