Nonlinear Dipole Inversion

Usage: qsmxt invert ndi [OPTIONS] --mask <MASK> --output <OUTPUT> --field-strength <FIELD_STRENGTH> --echo-times <ECHO_TIMES>... --magnitude <MAGNITUDE>... <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --field-strength <FIELD_STRENGTH>
          B0 field strength in Tesla

      --echo-times <ECHO_TIMES>...
          Echo times in seconds, every echo's, in order

      --magnitude <MAGNITUDE>...
          Magnitude NIfTI, the data weight (required): one 3D volume, a 4D one, or one per echo; several echoes are RSS-combined

      --ndi-tau <NDI_TAU>
          NDI gradient-descent step size (tau) (default: 2)

      --ndi-alpha <NDI_ALPHA>
          NDI L2 regularization weight (alpha) (default: 1e-5)

      --ndi-max-iter <NDI_MAX_ITER>
          NDI: Number of iterations (default: 100)

      --ndi-auto-stop <NDI_AUTO_STOP>
          NDI: stop automatically once noise starts to build up along the dipole cone (FANSI ndi_auto); --ndi-max-iter is then the maximum (default: false)

          [possible values: true, false]

      --ndi-te <TE>
          NDI: the echo time the field is converted to phase at: first, last, spacing (TE2 - TE1), sum (of the echo times), or a time in ms (default: first)

      --ndi-weight-norm <NORM>
          NDI magnitude-weight normaliser: global-max (the magnitude's maximum, as FANSI; default) or mask-p999 (its 99.9th percentile inside the mask; more consistent in vivo)

  -h, --help
          Print help
