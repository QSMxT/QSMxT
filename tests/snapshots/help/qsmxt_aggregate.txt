Run the dataset-level steps over runs already processed with `qsmxt run --no-dataset-steps` (multi-orientation, summary tables, provenance, clean-up)

Usage: qsmxt aggregate [OPTIONS] <BIDS_DIR> [OUTPUT_DIR]

Arguments:
  <BIDS_DIR>
          Input BIDS directory

  [OUTPUT_DIR]
          Output directory (defaults to bids_dir; outputs go into <dir>/derivatives/qsmxt/)

Options:
      --config <CONFIG>
          Pipeline configuration file (TOML)

      --include <INCLUDE>...
          Include only runs matching these glob patterns (e.g. "sub-1*" "*ses-pre*") (if omitted: every run)

      --exclude <EXCLUDE>...
          Exclude runs matching these glob patterns (e.g. "*mygrea*") (if omitted: none)

      --num-echoes <NUM_ECHOES>
          Limit number of echoes to process (if omitted: every echo)

      --pipeline <PIPELINE>
          Start from a pipeline: qsmxt-defaults, or an original toolbox's (medi-toolbox, sti-suite-ilsqr, sti-suite-star, qsmart, heidi, chi-sep-ilsqr, chi-sep-medi, chi-sepnet, decompose). The stages it covers (masking, field mapping, background removal, inversion, referencing, χ-separation) go back to QSMxT's defaults and then take the toolbox's settings; the other flags given then change any setting

          [possible values: qsmxt-defaults, medi-toolbox, sti-suite-ilsqr, sti-suite-star, qsmart, heidi, chi-sep-ilsqr, chi-sep-medi, chi-sepnet, decompose, uk-biobank]

      --orientation-group <PATTERN>
          Group runs into multi-orientation sets and reconstruct each with COSMOS or STI. Takes an entity name (acq, run, rec, inv), a glob over the run key (`*acq-dir*`), `re:` and a regex with one capture group, or `runs:` and the groups' run keys (`,` between runs, `;` between groups, each group's reference first). Orientations are co-registered if they need it (if omitted: each run is reconstructed on its own)

      --axial-resampling
          Resample oblique acquisitions onto an axial grid when their obliquity exceeds --obliquity-threshold. Off by default (methods that only work on axial data resample regardless)

      --no-axial-resampling
          Do not resample oblique acquisitions to axial (overrides a config's axial_resampling)

      --obliquity-threshold <OBLIQUITY_THRESHOLD>
          Obliquity in degrees above which --axial-resampling resamples (default: 10)

      --output-space <OUTPUT_SPACE>
          Grid to write derivatives on when the run was resampled to axial. `acquired` (default) puts them back where the data came from, so transforms you already hold still apply; `working` leaves them on the resampled grid and avoids a second interpolation

          [possible values: acquired, working]

      --ignore-slice-gap
          Reconstruct even when a 2D acquisition's sidecar `SliceThickness` is thinner than the slice pitch. Without it, QSM refuses such a run: the gap between slices is unsampled tissue, and the FFT kernels assume a contiguous grid, so the map would be wrong

      --tukey-window <TUKEY_WINDOW>
          Apply a k-space Tukey window with this taper ratio (0 to 1) to each echo's complex image before every other step, as the χ-separation toolbox does: 0.4, and 0 for Philips data. Default 0 (none). Needs magnitude images

      --crop-to-mask
          Reconstruct inside a box around the mask instead of the whole field of view. Cuts the FFT-bound stages roughly in proportion to the voxels removed, but those stages are a small share of a full run, so the end-to-end gain is usually modest. Off by default. Outputs are written on the full grid either way; this only changes where the arithmetic happens. Padding to an FFT-friendly size happens regardless

      --crop-margin-mm <CROP_MARGIN_MM>
          Margin in mm around the mask when --crop-to-mask is set (default 32). Below ~32 mm the reconstruction starts to differ from the uncropped one; it must also clear the largest SMV kernel in use, and V-SHARP defaults to 12 mm

      --fft-padding
          Pad the grid outward to an FFT-friendly size before the FFT-bound stages. Much faster on an awkward grid, and discards nothing, but it changes where k-space is sampled and so shifts the reconstruction slightly. Off by default

      --coil-combination-sigma <COIL_COMBINATION_SIGMA> <COIL_COMBINATION_SIGMA> <COIL_COMBINATION_SIGMA>
          MCPC-3D-S coil combination: smoothing sigma for the per-coil phase offsets (3 values, in voxels; default 10 10 5, as in MriResearchTools). Only used for uncombined multi-coil runs

      --mask-preset <MASK_PRESET>
          Mask preset: robust-threshold, bet, hd-bet (HD-BET deep-learning brain extraction + signal-gated erosion; needs a deep-learning build), bet-and-phase (BET on the magnitude AND a thresholded phase-quality map, then hole-filled and eroded), rs2-net (RS2-Net deep-learning rodent brain extraction), or mindgrab (MindGrab deep-learning brain extraction for any contrast; needs a deep-learning build) (default: robust-threshold)

          [possible values: robust-threshold, bet, hd-bet, bet-and-phase, rs2-net, mindgrab]

      --masking-input <MASKING_INPUT>
          Masking input image (overrides the input of the configured mask sections; combine with --mask-preset, e.g. --mask-preset robust-threshold --masking-input magnitude) (if omitted: the input each mask section names)

          [possible values: magnitude-first, magnitude, magnitude-last, phase-quality]

      --mask <MASK_SECTIONS_CLI>
          Define a mask section (repeatable; multiple sections are combined with --mask-combine). Format: <input>,<generator>,<refinement1>,<refinement2>,... Example: phase-quality,threshold:otsu,dilate:2,fill-holes:0,erode:2 Example: magnitude,bet:0.5,erode:2 Example: magnitude-first,bet:0.2,min-intensity:100,majority,close:2   (QSMART's mask) Example: magnitude,hd-bet,signal-erode   (HD-BET: `hd-bet[:full|window|XxYxZ|low-memory][:tta][:step=F]`; signal-erode: `signal-erode[:threshold[:depth_cap[:global_erosions[:bias_sigma[:min_component]]]]]`) (if omitted: the sections of --mask-preset)

      --mask-combine <MASK_COMBINE>
          How to combine multiple --mask sections: `or` (union, the default) or `and` (intersection — a voxel survives only where every section keeps it)

          Possible values:
          - or:  Union — keep a voxel any section keeps (default)
          - and: Intersection — keep only voxels every section keeps

      --mask-refine <MASK_REFINEMENTS_CLI>
          Refinement applied to the combined mask, after --mask-combine (repeatable). Takes the same refinement ops as --mask, e.g. `erode:2` or `fill-holes:0`; generators (threshold/bet/hd-bet) belong in a --mask section instead. Example: --mask-combine and --mask-refine fill-holes:0 --mask-refine erode:1 (if omitted: those of --mask-preset, if any)

      --use-custom-masks [<USE_CUSTOM_MASKS>]
          Prefer a bring-your-own mask from BIDS derivatives when present (else compute it). Bare flag = first matching derivatives tool (alphabetical); give a name (e.g. `bet`) to restrict to `derivatives/<tool>/sub-*/anat/*_mask.nii*`. Always falls back (if omitted: the mask is computed)

      --two-pass
          Two-pass artefact reduction: reconstruct a second time against a mask with holes at strong susceptibility sources, and merge the two reconstructions (how: --two-pass-mode). Strong sources (haemorrhage, calcification, implants) make the phase around them unrecoverable; leaving those voxels out keeps their streaking from spreading, while the ordinary mask still supplies values inside the holes. Roughly doubles background removal and inversion time, and is not free of downsides — where the holes were not artefactual it can be worse than a single pass. Based on doi:10.1002/mrm.29048 (Stewart et al.). Off by default. The conventional single-pass map is kept alongside as `_desc-singlepass_Chimap.nii`

      --bet-fractional-intensity <BET_FRACTIONAL_INTENSITY>
          BET fractional intensity (0.0-1.0; smaller = larger brain). Applies to every BET step in the masking recipe, overriding a `bet:<f>` in a --mask spec (if omitted: each BET step's own, 0.5 for a `bet` that gives none)

      --bet-voxel-scale <FACTOR>
          Factor applied to the voxel sizes before BET runs. BET's surface model is tuned to a human brain in millimetres, so preclinical data has to be presented at human scale: 10 is the usual setting for mouse. 1 (the default) is the acquisition's own geometry. Applies to every BET step in the masking recipe

      --bet-smoothness <BET_SMOOTHNESS>
          BET surface smoothness factor. Applies to every BET step in the masking recipe (default: 1)

      --bet-gradient-threshold <BET_GRADIENT_THRESHOLD>
          BET gradient threshold (-1 to 1). Applies to every BET step in the masking recipe (default: 0)

      --bet-iterations <BET_ITERATIONS>
          BET surface evolution iterations. Applies to every BET step in the masking recipe (default: 1000)

      --bet-subdivisions <BET_SUBDIVISIONS>
          BET icosphere subdivision level. Applies to every BET step in the masking recipe (default: 4)

      --bet-orientation <ORIENTATION>
          Which way round BET sees the left-right axis: `fsl` (the default; reversed for a neurologically stored image, as FSL's bet reads a NIfTI file) or `as-stored` (the voxels in the order they are stored, as MEDI's BET.m runs bet2). Applies to every BET step in the masking recipe

      --two-pass-mask <TWO_PASS_SECTIONS_CLI>
          Define the reliable-pass mask used by --two-pass (repeatable; same format as --mask). Defaults to `phase-quality,threshold:otsu` — an unfilled threshold on the phase-quality map. Its holes are the point, so refinements that close them (fill-holes, close, gaussian) defeat the method. Folded with --two-pass-mask-combine, then --mask-refine like the main mask, and always intersected with it

      --two-pass-mask-combine <TWO_PASS_MASK_COMBINE>
          How to combine multiple --two-pass-mask sections: `or` (union) or `and` (intersection). Defaults to the main mask's --mask-combine. Turns on --two-pass

          Possible values:
          - or:  Union — keep a voxel any section keeps (default)
          - and: Intersection — keep only voxels every section keeps

      --two-pass-mode <TWO_PASS_MODE>
          How --two-pass makes and merges its second pass. `local` (default): only holes with a core of very low phase quality are kept (strong sources, not veins or the pallidum), background removal leaves no eroded rim around them, and the second pass is used within 6 mm of them, blended into the first out to 12 mm. `original`: the published algorithm (doi:10.1002/mrm.29048), every voxel outside the reliable mask is a hole and the second pass is used wherever it is defined. Turns on --two-pass

          Possible values:
          - local:    Holes only at strong sources; second pass used near them (default)
          - original: The published algorithm

      --no-inhomogeneity-correction
          Disable inhomogeneity correction

      --inhomogeneity-correction
          Apply inhomogeneity correction to magnitude before masking

      --inhomogeneity-method <INHOMOGENEITY_METHOD>
          Inhomogeneity correction method: `makehomogeneous` (default; --homogeneity-*) or `n4` (N4 bias field correction, as ANTs' N4BiasFieldCorrection; --n4-*)

          Possible values:
          - makehomogeneous: Divide by a smoothed estimate of the receive sensitivity (MriResearchTools' makehomogeneous)
          - n4:              N4 bias field correction, as ANTs' N4BiasFieldCorrection

      --homogeneity-sigma-mm <HOMOGENEITY_SIGMA_MM>
          Inhomogeneity correction smoothing sigma in mm (makehomogeneous) (default: 7)

      --homogeneity-nbox <HOMOGENEITY_NBOX>
          makehomogeneous: boxes per dimension for the tissue segmentation the receive sensitivity is estimated from (default: 15)

      --n4-shrink-factor <N4_SHRINK_FACTOR>
          N4: Subsample the image by this factor before fitting the bias field (default: 4)

      --n4-max-iterations <ITERATIONS>...
          N4: maximum iterations at each fitting level, one number a level (default 50 50 50 50); the B-spline mesh doubles from one level to the next

      --n4-convergence-threshold <N4_CONVERGENCE_THRESHOLD>
          N4: stop a level once the change in the bias field (its coefficient of variation) falls to this (default 0: every iteration runs)

      --n4-mesh <X> <Y> <Z>
          N4: B-spline mesh elements per axis at the first level (x y z) (default: 1 1 1)

      --n4-spline-order <N4_SPLINE_ORDER>
          N4: order of the B-spline bias field, 1 to 3 (default: 3)

      --n4-bias-field-fwhm <N4_BIAS_FIELD_FWHM>
          N4: FWHM of the Gaussian modelling the bias field's blurring of the log-intensity histogram (default: 0.15)

      --n4-wiener-noise <N4_WIENER_NOISE>
          N4: Noise term of the Wiener deconvolution of the histogram (default: 0.01)

      --n4-histogram-bins <N4_HISTOGRAM_BINS>
          N4: Bins of the log-intensity histogram (default: 200)

      --n4-geometry <GEOMETRY>
          N4: the image geometry it is given: `scanner` (the scan's header, as ANTs reads the acquired NIfTI; the default) or `make-nii` (the axis-aligned header MATLAB's make_nii writes, as QSMART runs N4). N4's shrunk grid falls where the header puts it

      --motion-correction
          Rigidly co-register every echo onto a reference echo (estimated on magnitude, applied to phase through the complex signal) before field mapping, and restrict the mask to voxels every echo covers. Off by default. Needs magnitude images

      --motion-reference <first|last|N>
          Echo the others are aligned onto: `first` (default), `last`, or a 1-based echo number

      --no-motion-chain
          Register every echo from the identity instead of seeding it from its neighbour's solution

      --motion-chain-levels <MOTION_CHAIN_LEVELS>
          Pyramid levels for a seeded (chained) registration (default: 3)

      --motion-min-ncc <MOTION_MIN_NCC>
          NCC below which an echo's registration is reported as suspect (default 0.3, set for echoes; ~0.9 suits repeats)

      --registration-levels <REGISTRATION_LEVELS>
          Registration: Pyramid levels: the capture range; do not lower (default: 5)

      --registration-max-samples <REGISTRATION_MAX_SAMPLES>
          Registration: Voxels sampled per metric evaluation, per level (default: 200000)

      --registration-max-iterations <REGISTRATION_MAX_ITERATIONS>
          Registration: Powell cycles per level (default: 20)

      --registration-max-evaluations <REGISTRATION_MAX_EVALUATIONS>
          Registration: metric evaluations across all levels, a hard stop (default: 5000)

      --registration-tolerance <REGISTRATION_TOLERANCE>
          Registration: Relative cost improvement per cycle that counts as converged (default: 1e-5)

      --registration-rotation-step-deg <REGISTRATION_ROTATION_STEP_DEG>
          Registration: initial rotation step at the finest level, degrees (default: 3)

      --registration-translation-step-mm <REGISTRATION_TRANSLATION_STEP_MM>
          Registration: initial translation step at the finest level, mm (default: 3)

      --registration-min-overlap <REGISTRATION_MIN_OVERLAP>
          Registration: Smallest fraction of sampled voxels that must overlap (default: 0.25)

      --unwrapping-algorithm <UNWRAPPING_ALGORITHM>
          Unwrapping algorithm (default: romeo)

          [possible values: romeo, laplacian, prelude, medi-region-growing]

      --prelude-labelling <PRELUDE_LABELLING>
          PRELUDE: how the initial regions are labelled (default: auto)

          Possible values:
          - auto:   FSL prelude's default: slice by slice above 64 voxels in-plane, else over the whole volume
          - slices: Label regions slice by slice (FSL prelude --labelslices)
          - volume: Label regions over the whole volume (FSL prelude -f)

      --prelude-partitions <N>
          PRELUDE: number of phase partitions the initial regions are formed from (default: 8)

      --laplacian-solver <LAPLACIAN_SOLVER>
          Poisson solver for `--unwrapping-algorithm laplacian`: `dct` (unweighted least squares, Neumann/DCT solve; default), `fft` (Schofield & Zhu sin/cos Laplacian, FFT solve on a zero-padded volume), `mirror` (the same on the volume mirrored along each axis, as QSMART unwraps) or `mgpcg` (QSM.jl's MGPCG: Laplacian unwrapping with LBV background removal in one step; QSM.jl follows it with V-SHARP to remove remaining background)

          Possible values:
          - dct
          - fft
          - mirror: FFT solve on the volume mirrored along each axis, as QSMART unwraps
          - mgpcg:  QSM.jl's MGPCG: Laplacian unwrapping with LBV background removal in one step

      --laplacian-fft-pad <VOXELS>...
          Zero-padding in voxels per side for `--laplacian-solver fft`: one value for every axis, or three (x y z). Default 64

      --laplacian-unmasked
          `--unwrapping-algorithm laplacian`: unwrap the raw phase over the whole volume, instead of the phase set to zero outside the brain mask, as QSMART does. With `--b0-estimation qsmart-echofit` the field map is then kept over the whole volume

      --no-laplacian-unmasked
          `--unwrapping-algorithm laplacian`: unwrap the phase set to zero outside the brain mask (the default), after a `--pipeline` that unwraps the whole volume

      --laplacian-keep-outside
          `--unwrapping-algorithm laplacian` with a weighted-average echo combination: keep the field over the whole volume, not only inside the brain mask, as UK Biobank's pipeline hands it to V-SHARP

      --no-laplacian-keep-outside
          Keep the Laplacian field inside the brain mask only (the default), after a `--pipeline` that keeps it over the whole volume

      --phase-offset-removal <PHASE_OFFSET_REMOVAL>
          Remove the phase offset of multi-echo data with MCPC-3D-S (Eckstein et al., 2018) before unwrapping (default: true)

          [possible values: true, false]

      --phase-offset-sigma-mm <PHASE_OFFSET_SIGMA_MM> <PHASE_OFFSET_SIGMA_MM> <PHASE_OFFSET_SIGMA_MM>
          Phase offset removal smoothing sigma (3 values, in mm; default: 7 7 7, the ROMEO command line's)

      --bipolar-correction
          Enable bipolar gradient correction (requires >= 3 echoes)

      --romeo-individual
          ROMEO: unwrap each echo on its own (individual mode, for motion or time series)

      --no-romeo-individual
          ROMEO: unwrap the template echo spatially and the others temporally from it (default)

      --romeo-template <ROMEO_TEMPLATE>
          ROMEO: template echo index (1-indexed, only for template mode) (default: 1)

      --romeo-correct-global
          ROMEO: correct global 2π offsets, of each echo and between echoes (default: off)

      --no-romeo-correct-global
          ROMEO: do not correct global 2π offsets (default)

      --no-romeo-phase-coherence
          ROMEO: disable phase coherence weights (default: on)

      --no-romeo-phase-gradient-coherence
          ROMEO: disable phase gradient coherence weights (default: on)

      --no-romeo-phase-linearity
          ROMEO: disable phase linearity weights (default: on; the romeo command line's romeo3 weights)

      --romeo-phase-linearity
          ROMEO: enable phase linearity weights (default: on; for a --pipeline that turns them off)

      --no-romeo-mag-coherence
          ROMEO: disable magnitude coherence weights (default: on)

      --romeo-mag-weight
          ROMEO: enable magnitude weighting (default: off)

      --no-romeo-mag-weight
          ROMEO: disable magnitude weighting (overrides --romeo-mag-weight; kept for compatibility)

      --romeo-mag-weight2
          ROMEO: enable second magnitude weighting (flow-artifact penalty; default: off)

      --romeo-bestpath
          ROMEO: use Best-path (Abdul-Rahman) weights instead of ROMEO weights (default: off)

      --romeo-temporal-uncertain-unwrapping <ROMEO_TEMPORAL_UNCERTAIN_UNWRAPPING>
          ROMEO: temporal uncertain-unwrapping quality threshold [0,1] (0 disables; default: 0.5)

      --romeo-max-seeds <ROMEO_MAX_SEEDS>
          ROMEO: Maximum number of seed regions (default: 1)

      --romeo-merge-regions
          ROMEO: merge neighboring regions after unwrapping (default: off)

      --romeo-correct-regions
          ROMEO: correct each region's median to nearest 0 (default: off)

      --romeo-wrap-addition <ROMEO_WRAP_ADDITION>
          ROMEO: additional phase tolerance beyond π for neighbor differences [0,π] (default: 0.0)

      --qsm-per-echo <BOOL>
          Reconstruct a QSM from each echo on its own (each echo's phase unwrapped and divided by its echo time, then background removal, dipole inversion and referencing per echo) and publish each echo's map (`desc-echo<n>_Chimap`) and their mean as the QSM (`Chimap`), instead of one QSM from the echo-combined field map. The echo combination (--b0-estimation), phase-offset removal and bipolar correction do not run. DECOMPOSE takes the echoes' maps. Multi-echo only; not with TGV, QSMART, iQSM, iQFM, two-pass, or χ-separation methods that fit the local field (default: false)

          [possible values: true, false]

      --b0-estimation <B0_ESTIMATION>
          B0 field estimation method (default: weighted-avg)

          Possible values:
          - weighted-avg
          - linear-fit
          - robust-fit:     Motion-robust (IRLS) linear fit: down-weights echoes that depart from a straight line in TE, voxel by voxel. Needs 4 echoes (3 with --linear-fit-estimate-offset false)
          - qsmart-echofit: QSMART's echo fit: a magnitude-weighted fit of the unwrapped phase vs TE through the origin, which also marks the voxels QSMART leaves out
          - complex-fit:    MEDI's field map (Fit_ppm_complex): a magnitude-weighted fit of the complex echoes, then unwrapping of the fitted phase per echo spacing. Needs the magnitude and evenly spaced echoes; no phase offset removal is run first, and bipolar correction is refused

      --qsmart-fit-threshold-mode <QSMART_FIT_THRESHOLD_MODE>
          `--b0-estimation qsmart-echofit`: how the fit residual at which a voxel is left out of QSMART's reconstruction is set: a percentile of the blurred residual over the volume (`--qsmart-fit-percentile`), or a fixed residual (`--qsmart-fit-threshold`; default, QSMART v1.0's 40). Without it, giving one of those two selects its mode

          [possible values: percentile, absolute]

      --qsmart-fit-percentile <QSMART_FIT_PERCENTILE>
          `--b0-estimation qsmart-echofit`: the percentile of the blurred fit residual, in (0, 100], above which a voxel is left out of QSMART's reconstruction (default: 99)

      --qsmart-fit-threshold <QSMART_FIT_THRESHOLD>
          `--b0-estimation qsmart-echofit`: a fixed blurred fit residual above which a voxel is left out of QSMART's reconstruction, instead of a percentile (40 when the mode is `absolute` and none is given) (default: 40)

      --b0-weight-type <B0_WEIGHT_TYPE>
          B0 weighted averaging weight type. `assumed-decay` gives each echo's phase a fixed weight TE·exp(−TE/T2*) computed from the echo times and an assumed T2* (`--b0-weight-assumed-t2star`), the same in every voxel: no T2* map, no magnitude (Wang et al. 2022, Nat Neurosci 25:818). `phase-snr`, which uses the measured magnitude in each voxel, is generally preferable when magnitude is available. Applies to Laplacian unwrapping as well as ROMEO (default: phase-snr)

          [possible values: phase-snr, phase-var, average, tes, mag, assumed-decay]

      --b0-weight-assumed-t2star <MS>
          T2* in ms assumed by `--b0-weight-type assumed-decay` to compute its fixed echo weights (default 40; no T2* map is used)

      --linear-fit-estimate-offset <LINEAR_FIT_ESTIMATE_OFFSET>
          Linear and robust fit: estimate a phase offset term (default: true). The robust fit needs 4 echoes with it, 3 without

          [possible values: true, false]

      --robust-fit-loss <ROBUST_FIT_LOSS>
          Motion-robust fit (`--b0-estimation robust-fit`): loss turning residuals into weights. `tukey` (default) rejects echoes past the tuning radius; `huber` caps but never rejects

          [possible values: tukey, huber]

      --robust-fit-tuning <ROBUST_FIT_TUNING>
          Motion-robust fit: tuning radius in robust-scale units (default: the loss's conventional value, Tukey 4.685 / Huber 1.345). Smaller is more aggressive

      --robust-fit-iterations <ROBUST_FIT_ITERATIONS>
          Motion-robust fit: IRLS passes (default 3; 0 = report only, the field is the linear fit's)

      --robust-fit-downweight-level <ROBUST_FIT_DOWNWEIGHT_LEVEL>
          Motion-robust fit (reporting only): a robust weight below this counts as down-weighted (default 0.75; in (0, 1])

      --robust-fit-flag-ratio <ROBUST_FIT_FLAG_RATIO>
          Motion-robust fit (reporting only): flag an echo whose outlier score exceeds this many times the best echo's (default 3; at least 1)

      --complex-fit-reltol <COMPLEX_FIT_RELTOL>
          Complex fit (`--b0-estimation complex-fit`): stop once the update is this fraction of the first estimate, over the whole volume (default 1e-4)

      --complex-fit-max-iter <COMPLEX_FIT_MAX_ITER>
          Complex fit: Gauss-Newton iterations at most (default: 30)

      --bf-algorithm <BF_ALGORITHM>
          Background field removal algorithm (default: vsharp)

          Possible values:
          - vsharp
          - pdf
          - lbv
          - ismv
          - sharp
          - resharp
          - harperella
          - iharperella
          - bfrnet:      BFRnet deep-learning background removal (weights downloaded on first use)
          - iqfm:        iQFM deep-learning joint unwrapping + background removal from phase (weights downloaded on first use)

      --bf-erode-voxels <N>
          Erode the brain mask by N voxels after field mapping, before background removal; the field map is not masked again (default: 0, none)

      --bf-polish-mask
          After background removal, keep the mask's largest connected component with its holes filled and zero the local field outside it, as STI Suite's QSM_GUI does (PolishMask)

      --no-bf-polish-mask
          Do not polish the background-removal mask (the default), after a `--pipeline` that does

      --bf-ukb-mask-trim
          Trim the brain mask of voxels with unreliable phase before and after background removal, as UK Biobank's pipeline does (its phase-reliability maps of the first and last echo)

      --no-bf-ukb-mask-trim
          Do not trim the mask by phase reliability (the default), after a `--pipeline` that does

      --vsharp-deconvolve <BOOL>
          Undo V-SHARP's SMV high-pass with a truncated-SVD deconvolution (default: false)

          [possible values: true, false]

      --vsharp-threshold <VSHARP_THRESHOLD>
          V-SHARP deconvolution (TSVD) threshold; only used with --vsharp-deconvolve true (default: 0.05)

      --vsharp-max-radius <VSHARP_MAX_RADIUS>
          V-SHARP: Largest SMV kernel radius, in mm (default: 12)

      --vsharp-min-radius <VSHARP_MIN_RADIUS>
          V-SHARP: Smallest SMV kernel radius, in mm (default: 2)

      --vsharp-radius-step <MM>
          V-SHARP step between kernel radii in mm (default: 1); the radii run from --vsharp-max-radius down to --vsharp-min-radius

      --vsharp-grid <VSHARP_GRID>
          Grid V-SHARP estimates the background on: `isotropic` (default; spacing from --vsharp-grid-spacing), `native` (the acquired grid), or `finest` (isotropic at the smallest voxel dimension, e.g. 0.8 mm for 0.8x0.8x3 mm; no axis is coarsened). The local field keeps native resolution
