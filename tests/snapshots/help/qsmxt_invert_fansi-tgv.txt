FANSI Nonlinear Total Generalized Variation

Usage: qsmxt invert fansi-tgv [OPTIONS] --mask <MASK> --output <OUTPUT> --field-strength <FIELD_STRENGTH> --echo-times <ECHO_TIMES>... --magnitude <MAGNITUDE>... <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling) (if omitted: the whole volume at once)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --field-strength <FIELD_STRENGTH>
          B0 field strength in Tesla

      --echo-times <ECHO_TIMES>...
          Echo times in seconds, every echo's, in order

      --magnitude <MAGNITUDE>...
          Magnitude NIfTI, the data weight (required): one 3D volume, a 4D one, or one per echo; several echoes are RSS-combined

      --fansi-alpha1 <FANSI_ALPHA1>
          FANSI first-order (TV/TGV) L1 penalty weight (alpha1) (default: 0.0002)

      --fansi-mu1 <MU1>
          FANSI gradient-consistency ADMM weight (mu1), or auto for 100 × alpha1 (default: auto)

      --fansi-mu2 <FANSI_MU2>
          FANSI fidelity-consistency ADMM weight (mu2) (default: 1)

      --fansi-alpha0 <ALPHA0>
          FANSI second-order L1 penalty weight (alpha0, nlTGV only), or auto for 2 × alpha1 (default: auto)

      --fansi-mu0 <MU0>
          FANSI second-order consistency ADMM weight (mu0, nlTGV only), or auto for 2 × mu1 (default: auto)

      --fansi-max-iter <FANSI_MAX_ITER>
          FANSI: Number of outer ADMM iterations (default: 150)

      --fansi-tol-update <FANSI_TOL_UPDATE>
          FANSI: Percent-update stopping tolerance (default: 0.1)

      --fansi-tol-delta <FANSI_TOL_DELTA>
          FANSI: Inner Newton convergence tolerance (default: 1e-6)

      --fansi-te <TE>
          FANSI (nlTV and nlTGV): the echo time the field is converted to phase at: first, last, spacing (TE2 - TE1), sum (of the echo times), or a time in ms (default: spacing)

  -h, --help
          Print help
