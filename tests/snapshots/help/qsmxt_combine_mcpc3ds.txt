MCPC-3D-S (ASPIRE) coil combination from per-coil multi-echo phase + magnitude

Usage: qsmxt combine mcpc3ds [OPTIONS] --phase <PHASE>... --magnitude <MAGNITUDE>... --output <OUTPUT>

Options:
      --phase <PHASE>...
          Per-coil, per-echo wrapped phase NIfTI files (3D each). Files carrying BIDS `coil-NN` and `echo-N` entities are ordered by those; otherwise they are taken coil-major in the given order and `--num-echoes` is required

      --magnitude <MAGNITUDE>...
          Per-coil, per-echo magnitude NIfTI files, same layout as --phase

  -o, --output <OUTPUT>
          Output prefix: writes <prefix>_rec-mcpc3ds_echo-N_part-phase_<suffix>.nii, <prefix>_rec-mcpc3ds_echo-N_part-mag_<suffix>.nii and <prefix>_desc-mcpc3ds_mask.nii — the pipeline's names. <suffix> is the inputs' BIDS suffix (MEGRE when they carry none)

      --tes <TES>...
          Echo times in seconds, one per echo (read from the phase JSON sidecars when omitted)

      --num-echoes <NUM_ECHOES>
          Number of echoes when the file names carry no `echo-N` entity (if omitted: counted from those entities)

      --sigma <X> <Y> <Z>
          Smoothing sigma (voxels) for the per-coil phase offsets (default 10 10 5)

      --hip-unwrapping <HIP_UNWRAPPING>
          Unwrapping used on the coil-summed HIP phase

          [default: romeo]
          [possible values: romeo, laplacian, prelude, medi-region-growing]

      --prelude-labelling <PRELUDE_LABELLING>
          PRELUDE: how the initial regions are labelled (default: auto)

          Possible values:
          - auto:   FSL prelude's default: slice by slice above 64 voxels in-plane, else over the whole volume
          - slices: Label regions slice by slice (FSL prelude --labelslices)
          - volume: Label regions over the whole volume (FSL prelude -f)

      --prelude-partitions <N>
          PRELUDE: number of phase partitions the initial regions are formed from (default: 8)

  -h, --help
          Print help (see a summary with '-h')
