ROMEO-based multi-echo field mapping (phase offset removal + unwrap + B0 fit)

Usage: qsmxt fieldmap romeo [OPTIONS] --mask <MASK> --output <OUTPUT> <INPUT>

Arguments:
  <INPUT>
          Input multi-echo wrapped phase NIfTI file (4D: x,y,z,echo)

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output B0 field map NIfTI file (in ppm)

      --magnitude <MAGNITUDE>
          Multi-echo magnitude NIfTI file (4D; improves weighting)

      --tes <TES>...
          Echo times in seconds (space-separated, one per echo)

      --b0 <B0>
          Field strength in Tesla (alias: --field-strength)

      --params <PARAMS>
          JSON params file: {"TE":[..seconds], "B0":<tesla>, "voxel_size":[..], "B0_dir":[..]}. --tes / --b0 override values from this file when both are present

      --reliability-output <RELIABILITY_OUTPUT>
          `--b0-estimation qsmart-echofit`: also save its reliability map (1 = reliable) here, for `qsmxt qsmart --reliability`

      --field-mask-output <FIELD_MASK_OUTPUT>
          Also save the mask the field map is defined in here: the mask, less the voxels where phase offset removal could not estimate the phase offset (the field is 0 there). Pass it to `qsmxt bgremove` and the inversions in place of the mask

      --complex-fit-output <FILE>
          `--b0-estimation complex-fit`: also save the fit itself here, before spatial unwrapping: the phase accrued per echo spacing (radians, wrapped to [-π, π]; MEDI's `iFreq_raw`)

      --complex-fit-noise-output <FILE>
          `--b0-estimation complex-fit`: also save the fit's noise map here: the standard deviation of the phase per echo spacing, in radians (MEDI's `N_std`)

      --phase-offset-removal <PHASE_OFFSET_REMOVAL>
          Enable phase offset removal for multi-echo data (default: true)

          [possible values: true, false]

      --phase-offset-sigma-mm <PHASE_OFFSET_SIGMA_MM> <PHASE_OFFSET_SIGMA_MM> <PHASE_OFFSET_SIGMA_MM>
          Phase offset removal smoothing sigma (3 values, in mm; default: 7 7 7, the ROMEO command line's)

      --bipolar-correction
          Enable bipolar gradient correction (requires >= 3 echoes)

      --b0-estimation <B0_ESTIMATION>
          B0 field estimation method (default: weighted-avg)

          Possible values:
          - weighted-avg
          - linear-fit
          - robust-fit:     Motion-robust (IRLS) linear fit: down-weights echoes that depart from a straight line in TE, voxel by voxel. Needs 4 echoes (3 with --linear-fit-estimate-offset false)
          - qsmart-echofit: QSMART's echo fit: a magnitude-weighted fit of the unwrapped phase vs TE through the origin, which also marks the voxels QSMART leaves out
          - complex-fit:    MEDI's field map (Fit_ppm_complex): a magnitude-weighted fit of the complex echoes, then unwrapping of the fitted phase per echo spacing. Needs the magnitude and evenly spaced echoes; no phase offset removal is run first, and bipolar correction is refused

      --qsmart-fit-threshold-mode <QSMART_FIT_THRESHOLD_MODE>
          `--b0-estimation qsmart-echofit`: how the fit residual at which a voxel is left out of QSMART's reconstruction is set: a percentile of the blurred residual over the volume (`--qsmart-fit-percentile`), or a fixed residual (`--qsmart-fit-threshold`; default, QSMART v1.0's 40). Without it, giving one of those two selects its mode

          [possible values: percentile, absolute]

      --qsmart-fit-percentile <QSMART_FIT_PERCENTILE>
          `--b0-estimation qsmart-echofit`: the percentile of the blurred fit residual, in (0, 100], above which a voxel is left out of QSMART's reconstruction (default: 99)

      --qsmart-fit-threshold <QSMART_FIT_THRESHOLD>
          `--b0-estimation qsmart-echofit`: a fixed blurred fit residual above which a voxel is left out of QSMART's reconstruction, instead of a percentile (40 when the mode is `absolute` and none is given) (default: 40)

      --b0-weight-type <B0_WEIGHT_TYPE>
          B0 weighted averaging weight type. `assumed-decay` gives each echo's phase a fixed weight TE·exp(−TE/T2*) computed from the echo times and an assumed T2* (`--b0-weight-assumed-t2star`), the same in every voxel: no T2* map, no magnitude (Wang et al. 2022, Nat Neurosci 25:818). `phase-snr`, which uses the measured magnitude in each voxel, is generally preferable when magnitude is available. Applies to Laplacian unwrapping as well as ROMEO (default: phase-snr)

          [possible values: phase-snr, phase-var, average, tes, mag, assumed-decay]

      --b0-weight-assumed-t2star <MS>
          T2* in ms assumed by `--b0-weight-type assumed-decay` to compute its fixed echo weights (default 40; no T2* map is used)

      --linear-fit-estimate-offset <LINEAR_FIT_ESTIMATE_OFFSET>
          Linear and robust fit: estimate a phase offset term (default: true). The robust fit needs 4 echoes with it, 3 without

          [possible values: true, false]

      --robust-fit-loss <ROBUST_FIT_LOSS>
          Motion-robust fit (`--b0-estimation robust-fit`): loss turning residuals into weights. `tukey` (default) rejects echoes past the tuning radius; `huber` caps but never rejects

          [possible values: tukey, huber]

      --robust-fit-tuning <ROBUST_FIT_TUNING>
          Motion-robust fit: tuning radius in robust-scale units (default: the loss's conventional value, Tukey 4.685 / Huber 1.345). Smaller is more aggressive

      --robust-fit-iterations <ROBUST_FIT_ITERATIONS>
          Motion-robust fit: IRLS passes (default 3; 0 = report only, the field is the linear fit's)

      --robust-fit-downweight-level <ROBUST_FIT_DOWNWEIGHT_LEVEL>
          Motion-robust fit (reporting only): a robust weight below this counts as down-weighted (default 0.75; in (0, 1])

      --robust-fit-flag-ratio <ROBUST_FIT_FLAG_RATIO>
          Motion-robust fit (reporting only): flag an echo whose outlier score exceeds this many times the best echo's (default 3; at least 1)

      --complex-fit-reltol <COMPLEX_FIT_RELTOL>
          Complex fit (`--b0-estimation complex-fit`): stop once the update is this fraction of the first estimate, over the whole volume (default 1e-4)

      --complex-fit-max-iter <COMPLEX_FIT_MAX_ITER>
          Complex fit: Gauss-Newton iterations at most (default: 30)

      --romeo-individual
          ROMEO: unwrap each echo on its own (individual mode, for motion or time series)

      --no-romeo-individual
          ROMEO: unwrap the template echo spatially and the others temporally from it (default)

      --romeo-template <ROMEO_TEMPLATE>
          ROMEO: template echo index (1-indexed, only for template mode) (default: 1)

      --romeo-correct-global
          ROMEO: correct global 2π offsets, of each echo and between echoes (default: off)

      --no-romeo-correct-global
          ROMEO: do not correct global 2π offsets (default)

      --no-romeo-phase-coherence
          ROMEO: disable phase coherence weights (default: on)

      --no-romeo-phase-gradient-coherence
          ROMEO: disable phase gradient coherence weights (default: on)

      --no-romeo-phase-linearity
          ROMEO: disable phase linearity weights (default: on; the romeo command line's romeo3 weights)

      --romeo-phase-linearity
          ROMEO: enable phase linearity weights (default: on; for a --pipeline that turns them off)

      --no-romeo-mag-coherence
          ROMEO: disable magnitude coherence weights (default: on)

      --romeo-mag-weight
          ROMEO: enable magnitude weighting (default: off)

      --no-romeo-mag-weight
          ROMEO: disable magnitude weighting (overrides --romeo-mag-weight; kept for compatibility)

      --romeo-mag-weight2
          ROMEO: enable second magnitude weighting (flow-artifact penalty; default: off)

      --romeo-bestpath
          ROMEO: use Best-path (Abdul-Rahman) weights instead of ROMEO weights (default: off)

      --romeo-temporal-uncertain-unwrapping <ROMEO_TEMPORAL_UNCERTAIN_UNWRAPPING>
          ROMEO: temporal uncertain-unwrapping quality threshold [0,1] (0 disables; default: 0)

      --romeo-max-seeds <ROMEO_MAX_SEEDS>
          ROMEO: Maximum number of seed regions (default: 1)

      --romeo-merge-regions
          ROMEO: merge neighboring regions after unwrapping (default: off)

      --romeo-correct-regions
          ROMEO: correct each region's median to nearest 0 (default: off)

      --romeo-wrap-addition <ROMEO_WRAP_ADDITION>
          ROMEO: additional phase tolerance beyond π for neighbor differences [0,π] (default: 0.0)

  -h, --help
          Print help (see a summary with '-h')
