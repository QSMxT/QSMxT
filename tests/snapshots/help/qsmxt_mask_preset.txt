Run a `--mask-preset` recipe on an image (robust-threshold, bet, hd-bet, bet-and-phase, rs2-net, mindgrab)

Usage: qsmxt mask preset [OPTIONS] --output <OUTPUT> <PRESET> <INPUT>

Arguments:
  <PRESET>
          Which recipe — the same names as `run --mask-preset`

          [possible values: robust-threshold, bet, hd-bet, bet-and-phase, rs2-net, mindgrab]

  <INPUT>
          Input NIfTI file (an image for the generating subcommands, a mask for the rest)

Options:
  -o, --output <OUTPUT>
          Output mask NIfTI file

      --op <OPS>
          Further refinement, applied in order after the subcommand's own operation (repeatable). Examples: erode:2, dilate:1, fill-holes:0, close:1, gaussian:4.0, majority (3x3x3 majority filter), largest-component, imfill (every hole), min-intensity:100 (remove voxels below 100 in the input image; needs an image input), signal-erode (signal-gated erosion of low-signal boundary voxels; needs a magnitude input)

      --quality <QUALITY>
          Phase-quality map (from `qsmxt quality-map`) for the sections that read phase quality. Without it those sections read the input image instead, as `run --masking-input` would

      --phase <PHASE>
          Phase image (3-D, or 4-D multi-echo): the mask leaves out voxels where the scanner recorded no phase (a constant value in every echo), as `qsmxt run` does for every recipe. A phase-quality map rates that flat phase as reliable, so give this with `--quality`

      --bet-smoothness <BET_SMOOTHNESS>
          BET surface smoothness factor. Applies to every BET step in the masking recipe (default: 1)

      --bet-gradient-threshold <BET_GRADIENT_THRESHOLD>
          BET gradient threshold (-1 to 1). Applies to every BET step in the masking recipe (default: 0)

      --bet-iterations <BET_ITERATIONS>
          BET surface evolution iterations. Applies to every BET step in the masking recipe (default: 1000)

      --bet-subdivisions <BET_SUBDIVISIONS>
          BET icosphere subdivision level. Applies to every BET step in the masking recipe (default: 4)

      --bet-orientation <ORIENTATION>
          Which way round BET sees the left-right axis: `fsl` (the default; reversed for a neurologically stored image, as FSL's bet reads a NIfTI file) or `as-stored` (the voxels in the order they are stored, as MEDI's BET.m runs bet2). Applies to every BET step in the masking recipe

  -h, --help
          Print help
