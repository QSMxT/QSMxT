Check for updates and optionally install the latest version

Usage: qsmxt update [OPTIONS]

Options:
  -y, --yes
          Update without prompting for confirmation

      --force
          Replace a development build (version 0.0.0) with the latest release. Without it, `qsmxt update` refuses on a dev build, since every release would look newer

      --main
          Build the latest commit on the main branch from source and install it in place of this qsmxt. Needs the Rust toolchain (https://rustup.rs). The build is kept in ~/.qsmxt/build, so the next update rebuilds only what changed. `qsmxt update --force` goes back to the latest release

  -h, --help
          Print help
