χ-separation MEDI — local field + R2' + multi-echo magnitude + QSM

Usage: qsmxt separate chi-sep-medi [OPTIONS] --qsm <QSM> --mask <MASK> --output <OUTPUT> --local-field <LOCAL_FIELD> --r2prime <R2PRIME> --magnitude <MAGNITUDE>... --echo-times <ECHO_TIMES>...

Options:
      --qsm <QSM>
          Conventional QSM (χ_total) NIfTI in ppm

  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output prefix; writes {prefix}_desc-paramagnetic_Chimap.nii, {prefix}_desc-diamagnetic_Chimap.nii and {prefix}_desc-total_Chimap.nii — the pipeline's names

      --field-strength <FIELD_STRENGTH>
          B0 field strength in Tesla

          [default: 3]

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --local-field <LOCAL_FIELD>
          Local (tissue) field NIfTI in ppm

      --r2prime <R2PRIME>
          R2' map NIfTI in Hz

      --magnitude <MAGNITUDE>...
          Multi-echo magnitude: one 4D file or one 3D file per echo (space-separated)

      --echo-times <ECHO_TIMES>...
          GRE echo times in seconds (space- or comma-separated)

      --csf-mask <FILE|none>
          CSF mask NIfTI for the CSF-uniformity term, or `none` for no CSF term (the toolbox's GUI without a CSF mask) (default: the CSF found from R2* of the echoes, as the toolbox's script does; see --csf-r2star)

      --chi-sep-medi-lambda <CHI_SEP_MEDI_LAMBDA>
          χ-sep MEDI weight of the data terms against the L1 terms (default: 1)

      --chi-sep-medi-lambda-csf <CHI_SEP_MEDI_LAMBDA_CSF>
          χ-sep MEDI weight of the CSF-uniformity term (default: 1)

      --chi-sep-medi-dr-pos <HZ_PER_PPM>
          χ-sep MEDI paramagnetic relaxometric constant (Hz/ppm), or auto for 137 × B0 / 2.9 T (default: auto)

      --chi-sep-medi-dr-neg <HZ_PER_PPM>
          χ-sep MEDI diamagnetic relaxometric constant (Hz/ppm), or auto for 137 × B0 / 2.9 T (default: auto)

      --chi-sep-medi-pad <CHI_SEP_MEDI_PAD>
          χ-sep MEDI zero-padding at both ends of the third axis, in voxels (default: 5)

      --chi-sep-medi-tol <CHI_SEP_MEDI_TOL>
          χ-sep MEDI: stop when the relative change falls below this (default: 0.03)

      --chi-sep-medi-max-iter <CHI_SEP_MEDI_MAX_ITER>
          χ-sep MEDI maximum Gauss-Newton iterations (default: 30)

      --chi-sep-medi-cg-tol <CHI_SEP_MEDI_CG_TOL>
          χ-sep MEDI inner CG tolerance (default: 0.05)

      --chi-sep-medi-cg-max-iter <CHI_SEP_MEDI_CG_MAX_ITER>
          χ-sep MEDI inner CG max iterations (default: 100)

      --chi-sep-medi-csf-r2star <METHOD>
          χ-sep MEDI: the R2* its CSF mask is extracted from: arlo (MEDI's ARLO; the default) or nnls (the χ-separation toolbox's r2star_nnls, which its script runs)

  -h, --help
          Print help
