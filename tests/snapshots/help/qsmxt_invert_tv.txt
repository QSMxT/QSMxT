Total Variation (ADMM)

Usage: qsmxt invert tv [OPTIONS] --mask <MASK> --output <OUTPUT> <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --tv-lambda <TV_LAMBDA>
          TV-ADMM: L1 regularisation weight (larger = smoother) (default: 0.0003)

      --tv-rho <RHO>
          TV rho (ADMM penalty), or auto for 100 × lambda (default: auto)

      --tv-tol <TV_TOL>
          TV-ADMM: Convergence tolerance (default: 0.001)

      --tv-max-iter <TV_MAX_ITER>
          TV-ADMM: Maximum ADMM iterations (default: 250)

      --tv-pad <X> <Y> <Z>
          TV-ADMM: Zero-padding before the FFTs (x y z): at least this many, rounded up to an FFT-efficient size; -1 leaves an axis unpadded, in voxels (default: 0 0 0)

  -h, --help
          Print help
