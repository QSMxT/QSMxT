AMP-PE (Approximate Message Passing with Parameter Estimation)

Usage: qsmxt invert amp-pe [OPTIONS] --mask <MASK> --output <OUTPUT> --b0 <B0> <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling) (if omitted: the whole volume at once)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --magnitude <MAGNITUDE>...
          Magnitude NIfTI (data weight and morphology image): one 3D volume, a 4D one, or one per echo; several echoes are RSS-combined

      --b0 <B0>
          B0 field strength in Tesla (scales the simulated phase)

      --amp-pe-wave-order <AMP_PE_WAVE_ORDER>
          AMP-PE: Daubechies wavelet order (1=db1, 2=db2) (default: 1)

      --amp-pe-nlevel <AMP_PE_NLEVEL>
          AMP-PE: Wavelet decomposition levels (default: 3)

      --amp-pe-wave-pec <AMP_PE_WAVE_PEC>
          AMP-PE: Morphology-mask energy retention fraction (0.0-1.0) (default: 0.85)

      --amp-pe-simulated-te <AMP_PE_SIMULATED_TE>
          AMP-PE simulated echo time (s) used to turn the field into phase (default: 0.008)

      --amp-pe-max-linearization-ite <AMP_PE_MAX_LINEARIZATION_ITE>
          AMP-PE: Linearisation iterations per stage (default: 25)

      --amp-pe-tikhonov-beta <AMP_PE_TIKHONOV_BETA>
          AMP-PE: L2-seed Tikhonov weight (default: 0.02)

      --amp-pe-damp-rate-sig <AMP_PE_DAMP_RATE_SIG>
          AMP-PE: GAMP signal-update damping rate (default: 0.01)

      --amp-pe-damp-rate-par <AMP_PE_DAMP_RATE_PAR>
          AMP-PE: Parameter-estimation learning rate (kappa) (default: 0.1)

      --amp-pe-max-pe-spar-ite <AMP_PE_MAX_PE_SPAR_ITE>
          AMP-PE: Inner sparse-reconstruction iterations (default: 5)

      --amp-pe-max-pe-est-ite <AMP_PE_MAX_PE_EST_ITE>
          AMP-PE: Inner parameter-estimation iterations (default: 5)

      --amp-pe-cvg-thd <AMP_PE_CVG_THD>
          AMP-PE: GAMP inner convergence threshold (default: 1e-6)

  -h, --help
          Print help
