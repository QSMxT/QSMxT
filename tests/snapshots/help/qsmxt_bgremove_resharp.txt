Regularized SHARP (RESHARP) with Tikhonov regularization

Usage: qsmxt bgremove resharp [OPTIONS] --mask <MASK> --output <OUTPUT> <INPUT>

Arguments:
  <INPUT>
          Input total field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output local field NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --output-mask <OUTPUT_MASK>
          Output eroded mask (for algorithms that erode)

      --resharp-radius <RESHARP_RADIUS>
          RESHARP: SMV kernel radius, in mm (default: 3)

      --resharp-tik-reg <RESHARP_TIK_REG>
          RESHARP: Tikhonov regularisation parameter (default: 0.0001)

      --resharp-tol <RESHARP_TOL>
          RESHARP conjugate gradients squared (CGS) relative tolerance (default: 1e-6)

      --resharp-max-iter <RESHARP_MAX_ITER>
          RESHARP: Maximum CGS iterations (default: 200)

  -h, --help
          Print help
