χ-separation iLSQR (Shin 2021) — local field + R2' + QSM

Usage: qsmxt separate chi-sep-ilsqr [OPTIONS] --qsm <QSM> --mask <MASK> --output <OUTPUT> --local-field <LOCAL_FIELD> --r2prime <R2PRIME> --field-strength <FIELD_STRENGTH>

Options:
      --qsm <QSM>
          Conventional QSM (χ_total) NIfTI in ppm

  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output prefix; writes {prefix}_desc-paramagnetic_Chimap.nii, {prefix}_desc-diamagnetic_Chimap.nii and {prefix}_desc-total_Chimap.nii — the pipeline's names

      --field-strength <FIELD_STRENGTH>
          B0 field strength in Tesla

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --local-field <LOCAL_FIELD>
          Local (tissue) field NIfTI in ppm

      --r2prime <R2PRIME>
          R2' map NIfTI in Hz

      --chi-sep-ilsqr-dr-pos <HZ_PER_PPM>
          χ-sep iLSQR paramagnetic relaxometric constant (Hz/ppm), or auto for 137 × B0 / 2.9 T (default: auto)

      --chi-sep-ilsqr-dr-neg <HZ_PER_PPM>
          χ-sep iLSQR diamagnetic relaxometric constant (Hz/ppm), or auto for 137 × B0 / 2.9 T (default: auto)

      --chi-sep-ilsqr-pad <X> <Y> <Z>
          χ-sep iLSQR zero-padding at both ends of each axis in voxels, X Y Z (default: 16 16 16)

      --chi-sep-ilsqr-cg-max-iter-lsqr <CHI_SEP_ILSQR_CG_MAX_ITER_LSQR>
          χ-sep iLSQR: maximum CG iterations of the LSQR step (default: 50)

      --chi-sep-ilsqr-cg-tol-lsqr <CHI_SEP_ILSQR_CG_TOL_LSQR>
          χ-sep iLSQR: CG relative tolerance of the LSQR step (default: 0.02)

      --chi-sep-ilsqr-cg-max-iter-sa <CHI_SEP_ILSQR_CG_MAX_ITER_SA>
          χ-sep iLSQR: maximum CG iterations of the streaking-removal step (default: 50)

      --chi-sep-ilsqr-cg-tol-sa <CHI_SEP_ILSQR_CG_TOL_SA>
          χ-sep iLSQR: CG relative tolerance of the streaking-removal step (default: 0.02)

      --chi-sep-ilsqr-d2-thr <CHI_SEP_ILSQR_D2_THR>
          χ-sep iLSQR: the streaking cone is where |D| is below this (default: 0.11)

      --chi-sep-ilsqr-prc-w-i-min <CHI_SEP_ILSQR_PRC_W_I_MIN>
          χ-sep iLSQR: percentile of the field's Laplacian at which the LSQR weight is 1 (default: 60)

      --chi-sep-ilsqr-prc-w-i-max <CHI_SEP_ILSQR_PRC_W_I_MAX>
          χ-sep iLSQR: percentile of the field's Laplacian at which the LSQR weight is 0 (default: 99.8)

      --chi-sep-ilsqr-prc-w-g-min <CHI_SEP_ILSQR_PRC_W_G_MIN>
          χ-sep iLSQR: percentile of each gradient's magnitude at which the streaking-removal weight is 1 (default: 50)

      --chi-sep-ilsqr-prc-w-g-max <CHI_SEP_ILSQR_PRC_W_G_MAX>
          χ-sep iLSQR: percentile of each gradient's magnitude at which the streaking-removal weight is 0 (default: 70)

  -h, --help
          Print help
