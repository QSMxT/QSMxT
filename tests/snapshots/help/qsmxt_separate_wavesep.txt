WaveSep wavelet-L1 (Fang 2023) — QSM + R2'

Usage: qsmxt separate wavesep [OPTIONS] --qsm <QSM> --mask <MASK> --output <OUTPUT> --r2prime <R2PRIME>

Options:
      --qsm <QSM>
          Conventional QSM (χ_total) NIfTI in ppm

  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output prefix; writes {prefix}_desc-paramagnetic_Chimap.nii, {prefix}_desc-diamagnetic_Chimap.nii and {prefix}_desc-total_Chimap.nii — the pipeline's names

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --r2prime <R2PRIME>
          R2' map NIfTI in Hz

      --wavesep-dr-pos <WAVESEP_DR_POS>
          WaveSep paramagnetic relaxivity (Hz/ppm) (default: 137)

      --wavesep-dr-neg <WAVESEP_DR_NEG>
          WaveSep diamagnetic relaxivity (Hz/ppm) (default: 137)

      --wavesep-alpha <WAVESEP_ALPHA>
          WaveSep: Proximal-gradient step size (default: 0.2)

      --wavesep-lambda <WAVESEP_LAMBDA>
          WaveSep: Wavelet L1 soft-threshold weight (default: 0.02)

      --wavesep-wavelet-order <WAVESEP_WAVELET_ORDER>
          WaveSep: Daubechies order (default: 4)

      --wavesep-max-iter <WAVESEP_MAX_ITER>
          WaveSep: ISTA max iterations (default: 100)

      --wavesep-tol <WAVESEP_TOL>
          WaveSep: Relative-change stop tolerance (default: 0.001)

  -h, --help
          Print help
