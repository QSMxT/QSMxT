Weak-Harmonic QSM

Usage: qsmxt invert whqsm [OPTIONS] --mask <MASK> --output <OUTPUT> --field-strength <FIELD_STRENGTH> --echo-times <ECHO_TIMES>... <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --field-strength <FIELD_STRENGTH>
          B0 field strength in Tesla

      --echo-times <ECHO_TIMES>...
          Echo times in seconds, every echo's, in order

      --alpha1 <ALPHA1>
          TV regularization weight (alpha1)

      --mu1 <MU1>
          ADMM penalty for TV splitting (mu1)

      --mu2 <MU2>
          ADMM penalty for data-fidelity splitting (mu2)

      --beta <BETA>
          Weak-harmonic ROI penalty (beta)

      --muh <MUH>
          ADMM penalty for harmonic-field splitting (muh)

      --max-iter <MAX_ITER>
          Max iterations

      --tol-update <TOL_UPDATE>
          Percent-update convergence tolerance

      --tol-delta <TOL_DELTA>
          Inner Newton convergence tolerance

      --weight <WEIGHT>
          Data weight: flat (1 over the whole volume, WH_nlTV.m's default), flat-in-mask (1 inside the mask only), max-normalised (the magnitude over its maximum) or in-vivo (min(2 × magnitude / maximum, 1)); the last two need --magnitude (default: flat)

      --magnitude <MAGNITUDE>...
          Magnitude NIfTI, for a magnitude data weight (--weight): one 3D volume, a 4D one, or one per echo; several echoes are RSS-combined

      --te <TE>
          Echo time the field is converted to phase at: first, last, spacing (TE2 - TE1), sum (of the echo times), or a time in ms (default: first)

  -h, --help
          Print help
