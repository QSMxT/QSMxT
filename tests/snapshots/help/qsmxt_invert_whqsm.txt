Weak-Harmonic QSM

Usage: qsmxt invert whqsm [OPTIONS] --mask <MASK> --output <OUTPUT> --field-strength <FIELD_STRENGTH> --echo-times <ECHO_TIMES>... <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --field-strength <FIELD_STRENGTH>
          B0 field strength in Tesla

      --echo-times <ECHO_TIMES>...
          Echo times in seconds, every echo's, in order

      --magnitude <MAGNITUDE>...
          Magnitude NIfTI, for a magnitude data weight (--weight): one 3D volume, a 4D one, or one per echo; several echoes are RSS-combined

      --whqsm-alpha1 <WHQSM_ALPHA1>
          WH-QSM TV regularization weight (alpha1) (default: 0.0002)

      --whqsm-mu1 <WHQSM_MU1>
          WH-QSM ADMM penalty for TV splitting (mu1) (default: 0.02)

      --whqsm-mu2 <WHQSM_MU2>
          WH-QSM ADMM penalty for data-fidelity splitting (mu2) (default: 1)

      --whqsm-beta <WHQSM_BETA>
          WH-QSM weak-harmonic ROI penalty (beta) (default: 150)

      --whqsm-muh <WHQSM_MUH>
          WH-QSM ADMM penalty for harmonic-field splitting (muh) (default: 5)

      --whqsm-max-iter <WHQSM_MAX_ITER>
          WH-QSM: Maximum outer iterations (default: 150)

      --whqsm-tol-update <WHQSM_TOL_UPDATE>
          WH-QSM: Percent-update stopping tolerance (default: 0.1)

      --whqsm-tol-delta <WHQSM_TOL_DELTA>
          WH-QSM: Inner Newton stopping tolerance (default: 1e-6)

      --whqsm-weight <WEIGHT>
          WH-QSM data weight: flat (1 over the whole volume, WH_nlTV.m's default), flat-in-mask (1 inside the mask only), max-normalised (the magnitude over its maximum) or in-vivo (min(2 × magnitude / maximum, 1)); the last two need magnitude images (default: flat)

      --whqsm-te <TE>
          WH-QSM: the echo time the field is converted to phase at: first, last, spacing (TE2 - TE1), sum (of the echo times), or a time in ms (default: first)

  -h, --help
          Print help
