Variable radius SHARP (V-SHARP)

Usage: qsmxt bgremove vsharp [OPTIONS] --mask <MASK> --output <OUTPUT> <INPUT>

Arguments:
  <INPUT>
          Input total field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output local field NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --output-mask <OUTPUT_MASK>
          Output eroded mask (for algorithms that erode)

      --deconvolve <BOOL>
          Undo the SMV high-pass with a truncated-SVD deconvolution (default: false)

          [possible values: true, false]

      --threshold <THRESHOLD>
          Deconvolution (TSVD) threshold; only used with --deconvolve true

      --max-radius <MAX_RADIUS>
          Largest SMV kernel radius, in mm

      --min-radius <MIN_RADIUS>
          Smallest SMV kernel radius, in mm

      --radius-step <MM>
          Step between SMV kernel radii, in mm (default: 1); the radii run from --max-radius down to --min-radius

      --grid <GRID>
          Grid the background is estimated on: `isotropic` (default; spacing from --grid-spacing), `native` (the acquired grid), or `finest` (isotropic at the smallest voxel dimension, e.g. 0.8 mm for 0.8x0.8x3 mm; no axis is coarsened). The local field keeps native resolution

          [possible values: native, finest, isotropic]

      --grid-spacing <MM>
          Isotropic working-grid spacing in mm (default 1); used with --grid isotropic

      --ball <BALL>
          SMV ball: `default` (the voxels within r + 1/6 mm, centre excluded; a ball fits where all of it is in the mask) or `qsmjl` (QSM.jl's: within r, centre included)

          [possible values: default, qsmjl]

  -h, --help
          Print help
