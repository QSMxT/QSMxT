L1 Data-Fidelity QSM

Usage: qsmxt invert l1qsm [OPTIONS] --mask <MASK> --output <OUTPUT> --field-strength <FIELD_STRENGTH> --echo-times <ECHO_TIMES>... --magnitude <MAGNITUDE>... <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling) (if omitted: the whole volume at once)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --field-strength <FIELD_STRENGTH>
          B0 field strength in Tesla

      --echo-times <ECHO_TIMES>...
          Echo times in seconds, every echo's, in order

      --magnitude <MAGNITUDE>...
          Magnitude NIfTI, the data weight (required): one 3D volume, a 4D one, or one per echo; several echoes are RSS-combined

      --l1qsm-alpha1 <L1QSM_ALPHA1>
          L1-QSM gradient (TV) L1 penalty weight (alpha1) (default: 0.005)

      --l1qsm-mu1 <MU1>
          L1-QSM gradient-consistency ADMM weight (mu1), or auto for 100 × alpha1 (default: auto)

      --l1qsm-mu2 <L1QSM_MU2>
          L1-QSM fidelity-consistency ADMM weight (mu2) (default: 1)

      --l1qsm-mu3 <L1QSM_MU3>
          L1-QSM L1 proximal ADMM weight (mu3) (default: 1)

      --l1qsm-lambda <L1QSM_LAMBDA>
          L1-QSM L1 fidelity strength (lambda) (default: 0.8)

      --l1qsm-max-iter <L1QSM_MAX_ITER>
          L1-QSM: Number of outer ADMM iterations (default: 50)

      --l1qsm-tol-update <L1QSM_TOL_UPDATE>
          L1-QSM: Percent-update stopping tolerance (default: 1)

      --l1qsm-tol-delta <L1QSM_TOL_DELTA>
          L1-QSM: Inner Newton convergence tolerance (default: 1e-6)

      --l1qsm-te <TE>
          L1-QSM: the echo time the field is converted to phase at: first, last, spacing (TE2 - TE1), sum (of the echo times), or a time in ms (default: first)

  -h, --help
          Print help
