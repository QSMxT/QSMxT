Convert a DICOM directory to BIDS using automatic series classification

Usage: qsmxt dicom-convert [OPTIONS] <DICOM_DIR> <OUTPUT_DIR>

Arguments:
  <DICOM_DIR>
          Input DICOM directory (searched recursively)

  <OUTPUT_DIR>
          Output BIDS directory

Options:
      --dry-run
          Print the auto-detected series classification and exit without converting

      --keep-dicom-uids
          Keep the study's DICOM UIDs (Study, Series and Frame of Reference) and dates in the sidecars, so `qsmxt run --export-dicom` files its series into the original study. Patient identity is still removed, but the UIDs link the dataset to the original study: don't share such a dataset outside your site

  -h, --help
          Print help
