χ-sepnet deep-learning separation — local field + R2' or R2* (weights downloaded on first use)

Usage: qsmxt separate chi-sepnet [OPTIONS] --mask <MASK> --output <OUTPUT> --local-field <LOCAL_FIELD> <--r2prime <R2PRIME>|--r2star <R2STAR>>

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output prefix; writes {prefix}_desc-paramagnetic_Chimap.nii, {prefix}_desc-diamagnetic_Chimap.nii and {prefix}_desc-total_Chimap.nii — the pipeline's names

      --field-strength <FIELD_STRENGTH>
          B0 field strength in Tesla

          [default: 3]

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --local-field <LOCAL_FIELD>
          Local (tissue) field NIfTI in ppm

      --r2prime <R2PRIME>
          R2' map NIfTI in Hz (χ-sepnet-R2')

      --r2star <R2STAR>
          R2* map NIfTI in Hz (χ-sepnet-R2*: R2' predicted by R2PRIMEnet; `--route toolbox` only)

      --qsm <QSM>
          Conventional QSM (χ_total) NIfTI in ppm; `--route native` only (the toolbox route makes its own with QSMnetME)

      --chi-sepnet-route <CHI_SEPNET_ROUTE>
          χ-sepnet's input route. `toolbox` (default), the authors': the inputs resampled to 1 mm with B0 along z, the susceptibility channel computed by QSMnetME, R2' measured or predicted from R2* by R2PRIMEnet, the maps resampled back. `native`: the network alone on the acquired grid, given this run's QSM and R2'

          Possible values:
          - toolbox: The authors' route (training frame, QSMnetME susceptibility channel)
          - native:  The network alone on the acquired grid, given the QSM

      --chi-sepnet-patch <D> <H> <W>
          χ-sepnet (`--chi-sepnet-route native`) sliding-window patch in voxels, D H W, each a multiple of 16 (default: 192 192 128, the authors')

      --chi-sepnet-frame-patch <D> <H> <W>
          χ-sepnet (`--chi-sepnet-route toolbox`): run the networks as a sliding window of patches this size over the 1 mm frame, D H W, each a multiple of 16, so memory follows the patch. Omit to run the whole frame at once, as the authors do

      --r2primenet-ignore-field-mismatch
          Run R2PRIMEnet even when the acquisition is not at 3 T, the only field strength its weights were trained at; the predicted R2' is then uncalibrated. Without it, an explicit `--r2prime-strategy r2primenet` refuses a non-3 T run and `auto` skips R2' with a warning

  -h, --help
          Print help (see a summary with '-h')
