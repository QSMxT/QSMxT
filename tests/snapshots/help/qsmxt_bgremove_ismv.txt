Iterative Spherical Mean Value

Usage: qsmxt bgremove ismv [OPTIONS] --mask <MASK> --output <OUTPUT> <INPUT>

Arguments:
  <INPUT>
          Input total field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output local field NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --output-mask <OUTPUT_MASK>
          Output eroded mask (for algorithms that erode)

      --ismv-variant <VARIANT>
          iSMV implementation: wen2014 (the authors' paper and code) or qsmjl (QSM.jl's) (default: wen2014)

      --ismv-tol <ISMV_TOL>
          iSMV tolerance: the relative change between iterates it stops at (qsmjl: the residual relative to the first) (default: 5e-5)

      --ismv-max-iter <ISMV_MAX_ITER>
          iSMV max iterations (default: no limit)

      --ismv-radius <MM>
          iSMV kernel radius in mm, or auto for 6 × the smallest voxel dimension (qsmjl: 2 × the largest) (default: auto)

  -h, --help
          Print help
