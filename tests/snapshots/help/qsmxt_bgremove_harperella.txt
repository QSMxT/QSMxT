HARPERELLA integrated phase unwrapping + background removal

Usage: qsmxt bgremove harperella [OPTIONS] --mask <MASK> --output <OUTPUT> <INPUT>

Arguments:
  <INPUT>
          Input NIfTI: a wrapped echo in rad (with --te and --field-strength) or a total field in ppm

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output local field NIfTI file

      --output-mask <OUTPUT_MASK>
          Output eroded mask (for algorithms that erode)

      --te <TE>
          Echo time (s) of a wrapped-phase input. With --field-strength, the input is one wrapped echo in rad (the published method); without both, it is an unwrapped total field in ppm. The local field is written in ppm either way

      --field-strength <FIELD_STRENGTH>
          B0 field strength (T) of a wrapped-phase input — see --te

      --harperella-radius <HARPERELLA_RADIUS>
          HARPERELLA: SMV kernel radius, in mm (default: 10)

      --harperella-max-iter <HARPERELLA_MAX_ITER>
          HARPERELLA: Maximum iterations (default: 40)

      --harperella-tol <HARPERELLA_TOL>
          HARPERELLA: Convergence tolerance (default: 0.001)

      --harperella-pad <X> <Y> <Z>
          HARPERELLA zero-padding in voxels per side, X Y Z (default: 0 0 0)

      --harperella-rim <RIM>
          HARPERELLA boundary rim: whole (zero every Laplacian value in the rim; default) or sti (zero the 20 % largest, as STI Suite does)

  -h, --help
          Print help
