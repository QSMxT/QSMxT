Minimally regularised LSQR

Usage: qsmxt invert lsqr [OPTIONS] --mask <MASK> --output <OUTPUT> --magnitude <MAGNITUDE>... <INPUT>

Arguments:
  <INPUT>
          Input local field NIfTI file

Options:
  -m, --mask <MASK>
          Binary mask NIfTI file

  -o, --output <OUTPUT>
          Output susceptibility map NIfTI file

      --b0-direction <B0_DIRECTION> <B0_DIRECTION> <B0_DIRECTION>
          B0 direction (3 values)

          [default: 0 0 1]

      --tile-size <TILE_SIZE>
          DL tiling: output core size per patch, in voxels (enables tiling)

      --tile-halo <TILE_HALO>
          DL tiling: context margin per side, in voxels (default 8)

      --magnitude <MAGNITUDE>...
          Magnitude NIfTI, LSQR's row weight as the HEIDI package's (its scale does not change the solution): one 3D volume, a 4D one, or one per echo; several echoes are RSS-combined

      --b0 <B0>
          B0 field strength in Tesla — sets the default residual weighting

          [default: 3]

      --lsqr-residual-weighting <LSQR_RESIDUAL_WEIGHTING>
          LSQR residual-field weight `w` — the only thing regularising the solve. Omit to use qsm-core's field-strength-scaled default; 0 drops the residual term and streaks badly

      --no-lsqr-global-offset
          Do not fit a global field offset alongside χ

      --lsqr-tol <LSQR_TOL>
          LSQR convergence tolerance

      --lsqr-max-iter <LSQR_MAX_ITER>
          LSQR max iterations

  -h, --help
          Print help
