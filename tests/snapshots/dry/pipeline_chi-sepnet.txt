# Methods

QSM processing was performed using qsmxt (Stewart, 2026). Processing followed the χ-separation toolbox 1.1.3 pipeline. A brain mask was generated using BET brain extraction (Smith, 2002) of the RSS-combined magnitude image, in its stored voxel order as MEDI's BET.m runs it. Phase was converted to ppm with the scanner's centre frequency (ImagingFrequency). Phase offset removal was performed using MCPC-3D-S (Eckstein et al., 2018). Phase unwrapping was performed using ROMEO (Dymerska et al., 2021) with phase linearity disabled. The B0 field map was estimated as a weighted average of the unwrapped echo phases with per-echo weights TE·exp(−TE/T2*), computed from the echo times and an assumed T2* and identical in every voxel (Wang et al., 2022). Background field removal was performed using V-SHARP (Wu et al., 2012). The V-SHARP background was estimated on an isotropic grid: the field and mask were cropped to the brain mask's bounding box and resampled trilinearly, and the background field estimated there was interpolated back to the acquired grid, so the local field kept the acquired resolution. Dipole inversion was performed using iLSQR (Li et al., 2015). Susceptibility values were referenced to the mean susceptibility within the reconstruction mask (the brain mask less any rim eroded by background field removal). R2* maps were computed from multi-echo magnitude data using the ARLO method (Pei et al., 2015). Paramagnetic and diamagnetic susceptibility maps were computed using χ-sepnet (deep-learning source separation) (Kim et al., 2025) within the reconstruction mask, with the inputs resampled to 1 mm with B0 along z and the susceptibility channel computed by QSMnetME, as in the χ-separation toolbox, and the maps resampled back. Negative χ+ and |χ−| values were set to zero. χ-separation used R2' measured as R2* - R2 where a multi-echo spin-echo acquisition was available, and otherwise its own R2', estimated from R2* with R2PRIMEnet (Kim et al., 2025) in the network's training frame.
