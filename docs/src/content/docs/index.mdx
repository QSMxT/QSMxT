QSMxT takes you from raw scanner DICOMs to quantitative susceptibility maps with a
single self-contained binary. It finds the phase and magnitude pairs in a
[BIDS](https://bids.neuroimaging.io/) dataset, runs the reconstruction with
sensible defaults, and writes BIDS derivatives.

**Install** it with a single command:

<Tabs syncKey="os">
  <TabItem label="macOS / Linux">
    ```sh
    curl -fsSL https://raw.githubusercontent.com/QSMxT/QSMxT/main/install.sh | sh
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    irm https://raw.githubusercontent.com/QSMxT/QSMxT/main/install.ps1 | iex
    ```
  </TabItem>
</Tabs>

See the [installation guide](/QSMxT/getting-started/installation/) for other
options, or skip installing entirely and [try it in your browser](https://qsmbly.neurodesk.org/).

## Why QSMxT

<CardGrid>
	<Card title="End-to-end pipeline" icon="rocket">
		Masking, phase unwrapping, echo combination, background field removal,
		dipole inversion, and referencing — orchestrated for you.
	</Card>
	<Card title="10 inversion algorithms" icon="random">
		RTS, TV, TKD, TSVD, TGV, Tikhonov, NLTV, MEDI, iLSQR, and QSMART, all
		provided by [QSM.rs](https://github.com/astewartau/QSM.rs).
	</Card>
	<Card title="Interactive TUI" icon="laptop">
		Convert, configure, and run from a polished terminal interface — the
		recommended way to drive QSMxT, no config file required.
	</Card>
	<Card title="BIDS-native" icon="open-book">
		Finds phase and magnitude, reads JSON sidecars, and writes compliant
		derivatives to `derivatives/qsmxt/`. Starting from DICOMs, `dicom-convert`
		classifies the series for you.
	</Card>
	<Card title="Built for scale" icon="setting">
		Disk caching skips completed steps on re-runs, memory-aware parallelism
		fills your cores, and SLURM scripts fan out across a cluster.
	</Card>
</CardGrid>

## How do I cite QSMxT?

If QSMxT is useful in your research, please cite:

> Stewart AW, Robinson SD, O'Brien K, et al. "QSMxT: Robust masking and artifact
> reduction for quantitative susceptibility mapping." *Magnetic Resonance in
> Medicine* 87.3 (2022): 1289–1300. [doi.org/10.1002/mrm.29048](https://doi.org/10.1002/mrm.29048)

Every run also writes a `references.txt` listing citations for the specific
methods your data and settings exercised.
